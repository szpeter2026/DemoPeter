# szpeter2026 知识库 - 示例文档

## 项目简介

szpeter2026 是一个基于 RAG（检索增强生成）技术的本地知识库管理平台。

## 核心功能

### 1. 文档管理
- 支持 PDF、Markdown、TXT 三种格式
- 批量导入和智能分块
- 文档状态追踪和版本管理

### 2. RAG 智能问答
- 基于 Chroma 向量数据库的语义检索
- DeepSeek 和 Ollama 双 AI 模式
- 流式输出和来源追溯

### 3. Web 管理面板
- 实时统计仪表盘
- 文档管理界面
- 流式对话界面
- 报告生成中心

### 4. 报告系统
- 日报：每日知识库使用统计
- 周报：每周增长趋势分析
- 月报：月度总结和展望

## 技术架构

项目采用 Python + Flask + SQLite + Chroma 的轻量架构：

- **数据层**：SQLite 存储元数据和查询日志
- **向量层**：Chroma 管理文档嵌入向量
- **AI 层**：DeepSeek API 或 Ollama 本地模型
- **展示层**：Flask Web 面板 + RESTful API

## 设计原则

1. **轻量优先**：零配置启动，单文件数据库
2. **模块解耦**：各组件独立可替换
3. **隐私友好**：支持完全本地化运行
4. **易于扩展**：标准 API 接口，插件化架构
