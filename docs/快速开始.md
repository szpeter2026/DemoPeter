# szpeter2026 快速开始指南

## 第一步：环境检查

```powershell
# 确认 Python 版本（需要 3.10+）
python --version
```

## 第二步：初始化

```powershell
cd E:\szpeter2026
.\scripts\manage.ps1 -Action setup
```

这会：
- 安装 Python 依赖
- 创建 `.env` 配置文件
- 初始化 SQLite 元数据库

## 第三步：配置 AI

编辑 `.env` 文件：

**使用 DeepSeek（推荐，开箱即用）：**
```env
AI_PROVIDER=deepseek
DEEPSEEK_API_KEY=sk-your-deepseek-api-key
```

**使用 Ollama（本地，免费，隐私）：**
```env
AI_PROVIDER=ollama
OLLAMA_BASE_URL=http://localhost:11434
OLLAMA_MODEL=qwen2:latest
```

## 第四步：部署 Docker 服务栈（可选）

如需 Chroma 向量服务 + pgvector + Ollama Embedding 全套：

```powershell
cd "D:\Program Files\Docker"
docker compose up -d
```

这会启动 4 个容器：
- `szpeter2026-postgres` — PostgreSQL 17 + pgvector (:5432)
- `szpeter2026-chroma` — Chroma 向量库 (:8000)
- `szpeter2026-ollama` — Ollama LLM + Embedding (:11434)
- `szpeter2026-ollama-init` — 自动拉取模型（运行完退出）

首次启动会自动拉取 `qwen2.5:7b`（LLM）和 `nomic-embed-text`（Embedding），需等待几分钟。

编辑 `.env` 选择模式：

```env
# Chroma: 自动检测 Docker 服务
CHROMA_MODE=auto

# pgvector: 启用
PGVECTOR_ENABLED=true

# Embedding 模型
OLLAMA_EMBEDDING_MODEL=nomic-embed-text:latest

# 使用 Ollama 替代 DeepSeek（可选，完全离线）
AI_PROVIDER=ollama
OLLAMA_MODEL=qwen2.5:7b
```

三种 Chroma 模式可选：

| 模式 | 配置 | 说明 |
|------|------|------|
| `auto` | 默认 | 自动检测 Docker 服务，不可用时回退本地文件 |
| `persistent` | `CHROMA_MODE=persistent` | 纯本地文件存储，零依赖 |
| `remote` | `CHROMA_MODE=remote` | 仅使用 Docker Chroma 服务 |

### 使用 Docker Chroma 服务

```powershell
# 启动
cd "D:\Program Files\Docker\chroma"
docker compose up -d

# 查看状态
docker ps | findstr chroma

# 停止
docker compose down
```

### 使用本地持久化（零依赖）

编辑 `.env`：
```env
CHROMA_MODE=persistent
```

无需 Docker，向量数据自动存 `db/chroma_data/`。

## 第五步：导入文档

将你的文档放到 `knowledge_base/documents/` 目录下，然后：

```powershell
.\scripts\manage.ps1 -Action import
```

支持格式：`.md` / `.pdf` / `.txt`

## 第六步：启动 Web 面板

```powershell
.\scripts\manage.ps1 -Action web
```

浏览器访问：**http://127.0.0.1:5200**

## 常用操作

| 操作 | 命令 |
|------|------|
| 启动面板 | `.\scripts\manage.ps1 -Action web` |
| 导入文档 | `.\scripts\manage.ps1 -Action import` |
| 查看统计 | `.\scripts\manage.ps1 -Action stats` |
| CLI 查询 | `python scripts\query.py "你的问题"` |
| 生成报告 | `.\scripts\manage.ps1 -Action report` |
| 运行测试 | `.\scripts\manage.ps1 -Action test` |

## 故障排查

### Docker Chroma 不可用

系统自动回退到本地持久化模式（auto 默认行为），不影响使用。

手动检查：
```powershell
docker ps | findstr chroma
# 如果没有运行：
cd "D:\Program Files\Docker\chroma"
docker compose up -d
```

### DeepSeek API 报错

检查 `.env` 中的 `DEEPSEEK_API_KEY` 是否正确。

### 端口被占用

修改 `.env` 中的 `WEB_PORT`：
```env
WEB_PORT=5201
```
